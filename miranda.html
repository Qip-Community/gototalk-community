🦎 Miranda NG

Сборка от pirogprod для доступа к старым сетям

💡 О сборке

Это неофициальная сборка Miranda NG, созданная для работы с протоколами OSCAR (ICQ), MRIM (Mail.Ru Агент) и Jabber. В ней уже включены все необходимые плагины и настройки для подключения к сервисам PirogProd, KICQ и другим.

Сайт автора (pirogprod.ru) | Оригинальная страница сборки

📥 Шаг 1: Скачивание

Скачайте сборку Miranda NG для вашей версии Windows (32-бит или 64-бит).

Скачать x86 / 32 BIT → Скачать x64 / 64 BIT →

🔧 Шаг 2: Установка

Сборка портативная. Распакуйте скачанный архив в любую папку на компьютере и запустите файл miranda64.exe (или miranda32.exe для 32-битной версии). Профиль уже создан внутри сборки, Miranda не должна просить его создать.

🔑 Шаг 3: Настройка аккаунтов

Добавьте нужные учетные записи (ICQ, Jabber или MRIM). Для MRIM используйте сервер проектов Renaissance, PLMRIM и других, для ICQ — kicq.ru.

💻 Исходный код (GitHub)

Плагины PMLICQ и PMLMRIM — это отдельные проекты. Исходный код доступен для x86 и x64 версий.
